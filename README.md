## Описание проекта
DNS Promotional Landing Page - это современный лендинг для магазина электроники и бытовой техники DNS. Проект разработан с использованием React, TypeScript и Vite.

### Основные особенности
- 🛍️ Каталог товаров
- 🛒 Корзина покупок
- 👤 Профиль пользователя
- 📝 Система отзывов
- 🌙 Поддержка темной темы
- 📱 Адаптивный дизайн

## Технологии

### Основной стек
- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: 
  - Tailwind CSS
  - Tailwind Merge для условных стилей
  - Tailwind Animate для анимаций
  - Class Variance Authority для вариантов компонентов

### Управление состоянием
- **Глобальное состояние**:
  - React Context для темы, корзины и авторизации
  - React Query для кэширования и управления серверным состоянием
- **Формы**: React Hook Form с валидацией через Zod
- **Маршрутизация**: React Router v6

### UI компоненты
- **Библиотека компонентов**: 
  - Shadcn/ui (на основе Radix UI)
  - Lucide React для иконок
  - Embla Carousel для слайдеров
  - Recharts для графиков
- **Уведомления**: 
  - Radix UI Toast
  - Sonner для тостов
- **Модальные окна**: 
  - Radix UI Dialog
  - Vaul для мобильных модалок

### Интеграции
- **База данных**: Supabase
- **Анимации**: 
  - Tailwind Animate
  - Framer Motion (через Radix UI)

### Инструменты разработки
- **Линтинг**: ESLint
- **Форматирование**: Prettier
- **Типизация**: TypeScript
- **Стилизация**: 
  - PostCSS
  - Autoprefixer
  - Tailwind Typography

## Развертывание

### Подготовка к развертыванию
1. Убедитесь, что все зависимости установлены:
```bash
npm install
```

2. Соберите проект для продакшена:
```bash
npm run build
```

3. Проверьте, что все необходимые переменные окружения настроены:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

### Процесс развертывания
1. Загрузите собранные файлы из директории `dist` на ваш хостинг
2. Настройте сервер для обработки SPA (Single Page Application)
3. Убедитесь, что все маршруты перенаправляются на `index.html`
4. Проверьте доступность всех API-эндпоинтов

### Рекомендуемые настройки сервера
```nginx
location / {
  try_files $uri $uri/ /index.html;
  add_header Cache-Control "no-cache";
}

location /assets {
  expires 1y;
  add_header Cache-Control "public";
}
```
