## Описание проекта
DNS Promotional Landing Page - это современный лендинг для магазина электроники и бытовой техники DNS. Проект разработан с использованием React, TypeScript и Vite, с акцентом на производительность, SEO и пользовательский опыт.

### Основные особенности
- 🚀 Быстрая загрузка благодаря оптимизации Vite
- 📱 Адаптивный дизайн для всех устройств
- 🔍 SEO оптимизация
- 📲 PWA поддержка
- 🛡️ Улучшенная безопасность
- 🎨 Современный UI/UX дизайн

## Технологии
- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Styling**: CSS Modules
- **State Management**: React Context API
- **Routing**: React Router
- **Code Quality**: ESLint, Prettier
- **Testing**: Jest, React Testing Library

## Установка и запуск

### Предварительные требования
- Node.js (версия 18 или выше)
- npm или yarn

### Установка зависимостей
```bash
npm install
# или
yarn install
```

### Запуск в режиме разработки
```bash
npm run dev
# или
yarn dev
```

### Сборка для продакшена
```bash
npm run build
# или
yarn build
```

### Предпросмотр продакшен сборки
```bash
npm run preview
# или
yarn preview
```

- Open Graph теги для социальных сетей
- Twitter Card теги
- Структурированные данные (JSON-LD)

### Техническая SEO
- Оптимизированные изображения
- Правильная структура заголовков
- Семантическая разметка
- Карта сайта (sitemap.xml)
- Файл robots.txt

### Производительность
- Оптимизация загрузки ресурсов
- Предзагрузка критических ресурсов
- Оптимизация изображений

## Развертывание
### Подготовка к развертыванию
1. Убедитесь, что все зависимости установлены
2. Выполните сборку проекта
3. Проверьте все конфигурационные файлы

### Процесс развертывания
1. Загрузите собранные файлы на сервер
2. Настройте сервер для обработки SPA
3. Настройте SSL сертификат
4. Проверьте доступность всех ресурсов
